# Hardware Components

| Component | Function |
|---|---|
| ESP8266 NodeMCU | Main controller and telemetry/security processing node |
| DHT11 | Temperature and humidity measurement |
| MQ-135 | Gas sensor ADC level measurement |
| HC-SR04 | Ultrasonic distance / proximity measurement |
| Touch sensor | Local acknowledgement / buzzer silencing |
| Green LED | Normal-state indication |
| Yellow LED | Normal/load-status indication |
| Red LED | Danger-state indication |
| Buzzer | Audible danger alarm |

> The MQ-135 value is documented as an ADC level. No calibrated ppm conversion is claimed.
