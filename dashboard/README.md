# Streamlit Dashboard

The demonstrated Streamlit dashboard is the monitoring and visualization layer of the system.

Verified interface areas include:

- Device and MQTT state
- SQLite/database status
- Live sensor values
- Safety threshold comparison
- Actuator state
- Historical telemetry charts
- Cryptographic payload inspection
- Automatic refresh
- Database/event visibility

## Public-release status

The private dashboard source was not included in the verified public-release source bundle used to create this ZIP. It is therefore documented from the available project evidence rather than reconstructed from assumptions.

Representative screenshots are available under `screenshots/`.
